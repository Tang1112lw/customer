# 项目架构

（2026-10-10 重构后更新。二进制清单、用法与接口契约以 README.md 为准，本文只讲结构。）

## 概览

五个二进制，共享 `src/shared/` 的无界面工具：

- `src/main.rs` —— `aicrm_windows_api`（后台服务，无界面）：HTTP 接口（axum，
  127.0.0.1:8765）+ 云端命令通道。**零参数启动**：默认从 exe 同目录读
  `tools/`、`accounts/`、`data/`、`api.token`、`cloud.url`、`device.token`、
  `device.id`；命令行参数仍接受，但云端三项凭据**文件优先**。启动时把本次
  命令行记进 `data/state/startup.json`，供更新器重启时重放。
- `src/forckend/console.rs` —— `aicrm-console`（主窗口 + 托盘 + 登录/配对）：
  状态总览 / 配置页 / 账号菜单；托管本地服务（没了就拉起、掉了就重启）；
  首次未配对时显示「连接云端」引导页；登录与重新登录也在这一页完成。
- `src/forckend/setup.rs` —— `aicrm-setup`（静默安装器）：读自身末尾页脚解出
  载荷 → 跑 install.ps1 落盘 → 拉起客户端 → 自删。
- `src/update/main.rs` —— `aicrm-update`（原生更新器）：宽限期 → 复算摘要 →
  停客户端进程 → 备份 → 覆盖 → 重启 → 清理旧程序 → 刷新快捷方式 → 探活/回滚。
- `src/pack/main.rs` —— `aicrm-pack`（打包工具，不随包分发）：安装器 + 载荷
  拼成单文件。

## 共享层（src/shared/）

跨二进制的无界面工具，**文件之间零交叉引用**（每个文件都可单独按需引入）：

| 文件 | 职责 | 使用方 |
| --- | --- | --- |
| `paths.rs` | 安装目录与凭据文件位置的唯一约定 | 主控台 / 安装器 / 更新器 |
| `device.rs` | 设备标识、令牌落盘 + icacls 权限收紧 | 主控台 |
| `process.rs` | 杀进程名单与终止 / 探测（过渡期含已下线的旧程序） | 主控台 / 更新器 |
| `cache.rs` | 解密缓存探测（密钥"真的能用"与否） | 服务端 + 主控台 |
| `self_name.rs` | 从导出目录提取机主昵称 | 服务端 + 主控台 |
| `font.rs` | egui 中文字体（单独引入，不把 GUI 依赖带进服务） | 主控台 / 安装器 |
| `sha256.rs` | 无依赖摘要（单独引入） | 服务端 / 更新器 |

引入方式：工具/界面类二进制用 `#[path = "../shared/mod.rs"] mod shared;` 整体
引入；后台服务逐文件单独引入它需要的两个（cache / self_name）。

## 服务端结构（src/backend/）

`backend/mod.rs` 的 `app()` 组装全部路由并在顶层统一施加 Bearer 鉴权
（用 `route_layer`，未匹配路径保持 404）。模块按辅助程序拆分：
`service/key_service.rs`（AICRM-Key.exe）、`service/export_service.rs`
（aicrm-export-new.exe，Markdown 导出）、`service/archive_service.rs`
（归档打包上传）、`service/agent_service.rs`（云端命令通道：心跳 + 长轮询 +
令牌续期 + 自更新）。共享底座在 `service/mod.rs`。

## 令牌链路

```text
主控台「连接云端」→ HTTPS POST 云端 /api/auth/login（密码只经云端校验）
  → 写 account.name / api.token（icacls 收紧）/ api.refresh
  → 已配对：重启服务即生效；未配对：申领配对码 → install.ps1 落设备身份
服务启动读一次 api.token 做 Bearer 鉴权；每 30 分钟用 api.refresh 续期写回
```

## 界面约定

- 两个窗口（主控台 / 安装器）共享 `theme.rs`（各自 `mod theme;` 指向同一份文件）。
- 单实例：主控台与安装器共用命名互斥体 `Local\AICRM.WinClient`；重复启动把
  已有窗口 `SW_RESTORE` + 置前。
- 主控台不依赖服务：状态全部直接读安装目录里的文件（它的职责之一就是
  在服务没跑时把服务拉起来）。
- egui 自带字体不含 CJK，`shared/font.rs` 按 `msyh → simhei → Deng → simsun`
  顺序加载系统字体，否则整个界面是方框。

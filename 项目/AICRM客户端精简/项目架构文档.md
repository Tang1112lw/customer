# AICRM 客户端精简 —— 项目架构文档

## 一、架构设计（必须遵守）

- 仓库 `Desktop\客户端`，Rust 2024 edition，包名 `aicrm_windows_api`，版本 0.1.48。
- 五个 bin：`aicrm_windows_api`（后台服务，console 子系统，HKCU Run 开机自启直接拉起）、`aicrm-console`（GUI 主控台）、`aicrm-setup`（GUI 安装器）、`aicrm-update`（自更新器）、`aicrm-pack`（打包器）。
- `src/forckend/` 下 `theme.rs`、`cloud.rs` 被 console 与 setup 两个 bin 各自 `mod` 独立编译：**死代码 lint 按 bin 分别触发**，console 不用而 setup 用的共享项加 `#[allow(dead_code)]` 并注明原因（既有模式，同 `transport_warning`）。
- 窗口隐藏统一方案：子进程一律 `CREATE_NO_WINDOW`（0x08000000）；服务自身控制台窗口用 `hide_own_console()`（`GetConsoleWindow` + `ShowWindow(SW_HIDE)`，仅 release）自藏。
- 绑定状态判定口径（顶栏胶囊）：`accounts_ready`（密钥本体 + 解密缓存都在）才算「已绑定」；云端未登记但本机有可用密钥同样算已绑定；中间态（密钥不完整/缺密钥）一律显示「未绑定」。

## 二、方案设计（2026-10-12/13 本轮）

1. **CMD 窗口四项根治**：安装（`setup.rs` run_script 的 powershell）、登录写令牌（`credentials.rs` harden 的 icacls）、心跳探测（`agent_service.rs` wechat_process_running 的 tasklist）、辅助程序（`service/mod.rs` 新增 `hidden(&mut Command)`，run/version/help 三处）全部加 `CREATE_NO_WINDOW`。
2. **开机自启自藏**：`src/main.rs` 新增 `hide_own_console()`，main() 第一行调用；不动 println!/ctrl_c，避免 GUI 子系统 panic 风险。
3. **顶栏绑定胶囊**：`console.rs` 新增 `binding()` 返回 (颜色, 状态, 微信号)；`top_bar()` 重写为手工绘制胶囊（21px 高、圆角 10、alpha 26 淡底）+ 微信号 galley；整块为账号菜单点击区，悬停变 ACCENT；先按中性色量宽再定色重排。
4. **主界面精简**：删除 `wechat_card()`（密钥获取）、`cloud_card()`（云端连接）、`service_row()`（本地服务）及 `BIND` 常量；删除云端探针全家（`spawn_probe`/`probe_cloud`/`cloud_reachable`/`reachable` 字段/Arc+Mutex import）；`main_page()` 仅剩 `jobs_section()`；`Snapshot` 删除只写不读的 `token`、`credential_ready` 字段。
5. **配置入口隐藏**：`sidebar()` 注释掉「配置」nav_item（保留两行注释说明恢复方法）；`Page::Config` 与 `config_page()` 加 `#[allow(dead_code)]`，页面内容原样保留。
6. **登录页精简**：删「连接云端/重新登录」标题与副标题（改为 AICRM）、云端地址只读框、提示文字、明文传密码警告；按钮统一为「登录」。
7. **窗口缩小**：`with_inner_size` 780×604 → 560×480，固定尺寸不变；侧栏栏宽保持 110。
8. **账号下拉缩小**：宽 148→112、margin 6→5、圆角 10→8、anchor 偏移 160→122、`button_padding = (8,3)`。
9. **theme.rs**：删除 `card_head_rev`；`WARN`、`pill` 加 `#[allow(dead_code)]`（console 不用、setup 用）。
10. **cloud.rs**：`transport_warning` 加 `#[allow(dead_code)]`（console 不再展示，setup 仍用）。

**真 bug 修复（本轮删除引入的可达回归）**：
1. 托盘「停止服务」不置 `auto_service=false` → 下一轮 5 秒刷新的 `keep_service_alive` 立刻把服务拉回来，停止形同没停（HEAD 时唯一置位点是已删除的主界面按钮，托盘路径本就是潜在bug，删除后 100% 可达）。修：托盘 Stop 置 false、Start 置 true，与 README 记载行为一致。
2. `binding()` local_only 分支把 `wechat_name`（最近一次导出的昵称，无 wxid 归属记录）错配到 `accounts_ready.first()`，多就绪账号时张冠李戴（旧卡片同病）。修：仅当就绪账号数 = 1 时用昵称，否则回落 wxid。
3. 顶栏显示名无长度上限，超长昵称会把左侧标题顶出 560 宽窗口。修：`short_name()` 截断 24 字符 +「…」。
